# MoneyCore

MoneyCore is a Swift package for modeling, parsing,
formatting and calculating monetary values.

## Goals

MoneyCore aims to provide small, type-safe building blocks for
working with common monetary and financial concepts in Swift.

Planned areas include:

- Monetary values
- Currencies
- Locale-aware parsing and formatting
- Percentages
- Rounding
- Exchange rates
- Interest rates and basic financial calculations

## Status

🚧 Early development.

The public API may change before version 1.0.
